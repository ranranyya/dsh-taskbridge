# DSH TaskBridge 1.9.2 更新说明

## 摘要

`1.9.2` 保持 `1.9.0` / `1.9.1` 的 MCP 协议、工作树隔离与安全边界不变，重点完成 **Codex Code Mode 低耗直调与零截断治理**、**全链路长等待（`yield_time_ms: 1200000`）统一收口**、**本地审查单回合串联** 以及 **隔离工作树（`worktree`）验收后写回确认机制**：

1. **Codex Code Mode 低耗直调与参数契约内联（根治整组工具倾倒与输出截断）**：
   - 在 Codex 原生技能 `skills/dsh-taskbridge/SKILL.md` 的 frontmatter `description` 与正文 `## CODE MODE CALLS` 中明确直调 `tools.mcp__dsh_delegate__*`，禁止整组打印 `ALL_TOOLS`（避免全局 MCP `instructions` 复制拼接导致首轮触发 `exec` 默认 10,000 Token 截断），仅在确需查询缺省参数时按精确工具名切片读取 `exec tool declaration:`。
   - 在技能入口与按需附页 `rules-reference-<sha256>.md` 中补齐高频调用模板与跨字段契约（`delegate_plan` 单节点与 `nodes` 批量建树、`allowShared: true` 与 `autoPreflight: true` 联动、返工/子包复用省略 `autoPreflight`、`delegate_permission_decide` 精确 `fingerprint` 拷贝及 `delegate_question_answer` 答复格式）。
2. **Codex Code Mode 全链路静默长等待收口**：
   - 在首次 `delegate_submit({ wait: true })`、独立 `delegate_wait`、返工 `continueFromTaskId`、子包 `reuseWorktreeFromTaskId`、权限审批 `waitAfterDecision: true` 与提问答复 `waitAfterAnswer: true` 等全部等待入口统一声明 `// @exec: {"yield_time_ms": 1200000}`（杜绝回退为 `60000 ms` 短等待唤醒），并规范 `Script running with cell ID` 的单链续等行为。
3. **本地审查单回合串联与 `worktree` 验收后回写询问**：
   - Codex 端 `## LOCAL VERIFICATION` 将 `ready` 后的 `delegate_result({ taskId, includeDiff: false })` 回执校验与 `executionWorkspacePath` 内的单次组合验证命令紧凑收拢，减少审查拆步往返。
   - Codex 与 Antigravity 双端同步明确 `worktree` 隔离模式的收官交互：整条任务链完成 `accepted` 落盘（含最终 `delegate_plan` 总评）后，默认保持原仓库 `sourcePath` 不改动并汇报 `executionWorkspacePath`，同时在会话中用纯文本询问用户是否需要将已验收改动写回原工作目录（不调用阻塞式提问弹窗工具）；用户确认后先做冲突检查再本地安全同步，且不自动执行 `git commit`。
4. **7 题黑盒基准省流复验与无感升级哈希补登**：
   - `1.9.2` 候选构建在 Codex 7 题全集基准（`T0A`、`T0B`、`T1`–`T5`）中连续四轮 **7/7 满分通过（700/700）**，整组 `ALL_TOOLS` 倾倒、10k 输出截断、纯查工具回合与 MCP 参数报错全部清零为 **`0`**；相比 `1.9.1` 首个 `7/7` 满分场（`179` 步 / `1,139.2 万` 总 Token），7 题主控步数压降至 **`113–126` 步（降幅 `29.6%–36.9%`）**、含缓存总 Token 压降至 **`641.4 万–751.1 万`（降幅 `34.1%–43.7%`）**，其中重型三域重构题 `T5` 从 `78 步 / 698.9 万` 压降至 **`34–43 步 / 276.5 万–381.2 万`（降幅 `45.5%–60.4%`）**，主控代码输出较无插件基线净省 **`44.2%–69.5%`**；双端产品简介（`README.md`、`docs/INTRODUCTION.zh.md`、`docs/INTRODUCTION.md`）已同步刷新为 `1.9.1` / `1.9.2` 最新基准数据。
   - 在 `src/codex/installer.js` 与 `src/antigravity/installer.js` 中补登已发布 `1.9.1`（LF / CRLF）及 `1.9.2` 各轮测试包的精确 `SKILL.md` SHA-256 哈希，确保既有托管安装可无缝自动刷新到 `1.9.2` 并完整保留用户自定义修改。

## 升级说明

- **从 `1.9.1`、`1.9.0` 或更早版本升级**：在 DSH 插件管理页直接升级或本地安装 `dsh-taskbridge-1.9.2.tgz` 并启用；DSH 启动自检会自动将未修改过的旧版 Codex / Antigravity 托管技能刷新至 `1.9.2`（也可在插件设置页对应集成标签手动点击更新），重开宿主会话即可生效。既有接口配置、本机调用开关与历史任务记录全部原样保留。
