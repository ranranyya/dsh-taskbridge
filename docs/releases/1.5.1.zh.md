# DSH TaskBridge 1.5.1 更新说明

发布日期：2026 年 11 月 15 日。安装标识：`dsh-taskbridge@1.5.1`。

**让你的 Claude Code 或 Codex 指挥 DSH 工作，在 DSH 插件中选择已有 API、执行模型和思考强度。**

1.5.1 延续派工、静默等待、必要审批、集中审查和同任务续接流程，重点修复设置交互、更新误报冲突和重复失败提醒的确认可靠性。CLI 执行通道和 Claude Code 一键安装不在本次更新范围内。

## 主要变化

### 设置自动保存

- 移除页面底部额外的保存按钮。
- 文本输入停止约 700ms 后合并保存，主要开关和下拉选择及时保存。
- 写入串行处理，避免较早的响应覆盖较新的设置；无效草稿保留，方便继续修正。
- 正在执行的任务使用派工时的配置快照，不被中途设置改动偷偷切换 API 或模型。

### 更新后 Codex 集成不再反复误报冲突

- 支持 Codex 根配置目录为正常符号链接或 Windows Junction，解析并固定到真实目录后操作，保留原有根链接。
- 每次插件激活从当前安装包刷新版本信息，避免热更新缓存旧版本、给新规则写上旧版本号。
- 识别正式 1.5.0、已发出的本地候选以及已观察到的旧版本戳产物的精确原版文件，支持升级到 1.5.1。
- 用户真正修改过的 agent 或自定义 MCP 配置仍保留；异常的 agents 子目录和最终文件链接仍拒绝。

### 任务详情和审查意见可正常打开

- 打开、重复打开或切换任务时，详情展示在列表上方并定位到详情区域。
- 完整审查意见保留全文，后台列表刷新不再用摘要覆盖已经打开的内容。
- 长意见继续按现有边界和分页协议读取，不暗中截短。

### 失败提醒要收到确认才清除

- 连续相同工具失败的提醒具有稳定 eventId，回包丢失后仍可重取同一事件。
- `delegate_wait` 新增可选 `ackFailureEventId`，返回明确的 `failureAck`；正确确认幂等，错误 ID 不会清除提醒。
- 长审批、普通问答及网络错误等返回路径保留已经应用的确认事实，减少重复处理。
- 旧客户端仍可使用原参数，但未确认提醒可能重发；请同步加载新版托管规则。

### 指挥规则、恢复和团队选择

- 正常执行只静默等待，执行者处理普通单项失败；指挥端在审批、真实异常和交付时介入，交付后集中、有界审查。
- 同链身份无变化时复用已有预检事实；引擎仍逐次核验 checkout，审查结论必须确认保存。
- DSH 重启后可从已验证的任务身份、真实目录及 Git worktree 登记恢复原隔离工作区，不新建替代副本。
- 新增逐任务 `agentTeams` 决定，由指挥端按复杂度选择；不改变用户选定的提供方、执行模型或思考强度。省略表示不作新决定，续接可继承。
- 限制长会话 metrics 中展示的样本数量，保留累计统计和明确的省略数量，避免返回整体超过预算。

## 验证

- 正式源码完整回归：1567 项通过，无失败、跳过或取消；前端构建一致性检查通过。
- Windows DSH 原生页面实测自动保存并恢复原值、重复打开详情、任务切换及 435 字符完整审查意见。
- 候选通过原生插件管理覆盖安装；热更新、重复点击安装更新、DSH 重启均无 Codex 集成冲突。已安装 C 盘 Junction 实际定位到 E 盘，根链接和正确配置保持不变。
- 真实 `workbuddy / deepseek-v4.1-flash / max` 任务连续三次读取故意缺失文件，再执行普通权限 90 秒等待。新旧客户端取得相同提醒；错误确认保留、正确确认清除、重复确认幂等；随后默认长等待直到交付，集中审查结论 saved/durable。
- 正式包另做解包、版本与 MCP 握手、旧版／候选模板升级和自定义内容保留检查。

这是特定 Windows 环境与所述提供方的验收，不等同于所有平台、模型或故障组合已经实测。

## 已知限制

- 失败提醒没有新增跨进程持久化，重启前未确认的提醒不保证恢复。
- 既有历史预算若裁剪了可信审批证据，重启后可能拒绝该历史任务续接并返回 `JOB_TASK_NOT_FOUND`；本版不放宽完整证据要求。
- 团队成员提权桥接尚未实现；成员默认审批策略为 `never`，需要更大权限的具体操作应回到主执行者逐次申请。真实验收验证了团队关闭，未创建真实成员进行提权验收。
- 最终 `MCP_RESULT_OVER_BUDGET` 拒绝兜底没有独立反例覆盖；完整一小时客户端边界及全部提供方异常组合未覆盖。
- 本版没有新的同条件 token 账单对照，不宣称比 1.5.0 再节省固定比例。此前样本及适用边界见 [1.5.0 账单对照](1.5.0-token-benchmark.zh.md)。

## 更新

等待当前任务结束，在 DSH 插件管理中更新 `dsh-taskbridge`，或添加 `dsh-taskbridge@1.5.1`；也可安装本 Release 的 `dsh-taskbridge-1.5.1.tgz` 并核对 SHA256。区域镜像未同步时改选 npm 官方源。

已安装且未修改的 Codex 托管规则在插件启用时刷新；首次安装仍需点击 Codex 集成中的安装按钮。客户端若缓存旧 MCP 定义，请重新连接或新开会话。不要同时启用旧 Delegate／TaskDispatch 和 TaskBridge。

本项目自定义插件索引随 GitHub Release 更新，订阅该索引后可发现相应版本；这不是承诺被所有 DSH 内置市场自动收录。本地压缩包来源是否显示自动更新取决于客户端来源管理，必要时用上述包名安装。
