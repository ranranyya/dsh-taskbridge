# TaskBridge 1.6.0

在插件的「任务记录」页可以围绕总目标创建多层规划。每个子任务保留自己的执行身份，同一任务的首次执行与后续整改按轮次显示。执行完成后先进入待审查，结论保存后才计为验收通过。总目标仍有子任务或分支需要处理时，会继续显示相应状态。

任务按已核实的源项目分组。可以按项目、任务标题和编号搜索，再用状态缩小范围。点击对应轮次的「详情」可原位读到审查意见和执行信息。选中「已归档」可找回归档的任务，并恢复到主列表。后续整改会重新显示这一任务。历史记录仍按既有保留规则管理。

DSH 左侧的「TaskBridge 任务」打开项目导航。在当前 DSH 中仍可定位的会话可以从这里打开。找不到原生会话或会话已被 DSH 归档时，页面会说明原因。多层规划在「任务记录」页查看，DSH 的工作区和会话继续在宿主页面管理。

修复续接中明确指定 `max` 却被自动降档的问题。指定具体档位时，当轮首条及后续模型请求保持该档位。TaskBridge 设为「不指定」且 DSH 设为 `auto` 时，继续按工具记录自动调档。

从 1.5.4 更新时沿用已有历史与用户设置。当前支持通过 Codex 接入，其他客户端的计划见 [兼容说明](../runtime-compatibility.md)。
