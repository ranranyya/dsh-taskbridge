# DSH TaskBridge 1.5.0 更新说明

发布日期：2026年11月15日。安装标识：`dsh-taskbridge@1.5.0`。

让你的 Claude Code 或 Codex 指挥 DSH 工作，在 DSH 插件中选择已有 API、执行模型和思考强度。1.5.0 的重点是把“派工—静默等待—必要判断—集中审查—续接修正”接成完整流程。

## 为什么是1.5.0

这次不仅修复缺陷，还新增普通提问回答工具、程序计量工具，以及审批或回答后在同一调用内继续等待的能力。旧调用方式保持兼容，因此按新增功能的小版本准备1.5.0，1.4.3仅作为此前本地测试包的版本前缀，不另行发布。

## 新功能

- **审批后直接续等。** `delegate_permission_decide` 支持 `waitAfterDecision: true`，指挥端决定当前请求后，程序直接等下一事件，不必再调用一次模型来恢复等待。
- **普通问题及时转交。** 接入 DSH 原生 `ask_user_question`，新增 `delegate_question_answer`。问题出现时立即返回完整题目和选项；`waitAfterAnswer: true` 可在回答后直接续等。
- **程序调用计量。** 新增只读 `delegate_metrics`，统计工具调用、等待返回、原因、内部观察、返回字节及决定/回答事实。它不把程序内部观察当作GPT响应，也不虚构宿主token或费用。
- **集中审查规则。** 正常执行期间由程序等待；只处理提问、审批、真实异常和交付。审查后写回结论，有问题通过 `continueFromTaskId` 续接原对话。

## 修正与边界

- 正常的 `dsh-delegate`、`dsh-taskbridge` 目录不再被误脱敏。显示投影与可恢复身份分离，恢复时核对真实路径和摘要，拒绝矛盾或证据不足的续接。
- 审批参数单项上限8192字符、总上限16384字符。证据超过边界时明确不可批准，不根据残缺命令授权。
- 拒绝理由注入同一个执行Agent，并记录是否成功送达；原操作仍保持拒绝，新操作必须重新申请。
- 问题完整传送或明确不可回答。过期、取消、换会话、原调用失效及重复回答都受核验；问题回答不授予权限。
- 大答案回执不会挤掉新题目或丢失已经应用的事实。已应用后等待失败仍保留回执，结果未知时不自动重送决定或答案。
- MCP与插件版本从安装包清单读取。Codex托管升级识别正式1.4.2和已验证的本地test.1/test.2原版规则；自定义文件保持原样。
- 继续默认通用加载，不声明DSH版本白名单；所需接口仍按实际能力检查。未新增CLI执行通道或Claude Code一键安装。

## Codex token实测

用户提供的2026年11月14日至15日账单，与同一Codex聊天的响应记录按非缓存输入、缓存读取、输出三项用量逐条匹配。

优化前等待样本48次模型响应，等待相关token共9,986,839；本次候选等待样本3次响应，共457,224，**样本总量减少95.42%**。两项任务时长不同，按实际执行时长折算，等待相关token/分钟减少**94.46%**。

这不是整个任务或所有用户的固定节省率。旧任务有29次审批，新长时验收没有审批，且上下文大小不同。只比较相同的“外层续等”动作时，token/分钟减少**90.07%**。完整口径、账单费用与交付后审查成本见[真实账单对照报告](1.5.0-token-benchmark.zh.md)。

## 已验证

在Windows上的本地test.2候选完成：

- 原生提问转交、回答后续等、正式拒绝反馈送达、972字符完整命令审批、90秒操作、集中审查持久化。
- 真正重启Desktop和插件运行时、监听端口改变后，仍保留已接受结论并续接同一Session；执行者不读文件就准确回忆旧上下文。
- 真实选择的模型串行完成12轮100秒的计时/只读哈希校验，整轮约21分23秒。只有1次MCP等待和1次ready返回，执行中结果查询为0；外层客户端到期后继续同一exec。
- test.2候选1465项完整自动测试通过；同步1.5.0版本戳并补充test.2托管规则迁移后，完整回归1468项全部通过，针对性检查160项通过。发布包本身另做解包、MCP握手与升级验证。

这些证据不能代替所有平台、提供方、Claude Code客户端、一小时等待上限和全部故障组合的实测。插件不保证跨客户端绝对零模型唤醒；旧记录若已经丢失可信路径证据，也不能凭空恢复。

## 更新方法

正式上线后，在DSH插件管理中更新 `dsh-taskbridge`，或添加 `dsh-taskbridge@1.5.0`；也可安装本Release提供的 `dsh-taskbridge-1.5.0.tgz` 并核对SHA256。区域镜像未同步时改选npm官方源。不要手工改写Desktop保留的profile。

原版Codex托管规则可在插件启动时刷新；尚未安装的集成仍需在设置页点击安装按钮。已有客户端若仍缓存旧MCP工具定义，需要重新连接或新开会话，确认能看到 `delegate_question_answer` 等10个工具。不要同时启用旧Delegate/TaskDispatch与TaskBridge。
