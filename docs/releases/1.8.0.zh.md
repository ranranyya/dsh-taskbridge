# TaskBridge 1.8.0

## 核心更新

- **新增 Antigravity 一键集成**：设置页新增独立「Antigravity 集成」标签页，可将自包含插件包安装至 `~/.gemini/config/plugins/dsh-taskbridge/`（内含 `plugin.json`、按需加载的 `SKILL.md`、仅保留只读与 MCP 工具的后台派工子智能体 `agents/dsh-taskbridge.md` 与独立 `mcp_config.json`），不修改 Antigravity 全局配置。支持安装/更新、仅修复 MCP、移除托管项与 DSH 启动自动刷新；按文件哈希逐文件保护自定义修改，不影响其余托管文件升级或补装。
- **三层黑盒架构优化（Codex 端大幅瘦身）**：
  - 底层 `worker-prompt.js` 自动注入“共享或脏工作区保留已有未提交修改”与“测试读取后清理新建未追踪临时日志”约束。
  - 精简 `codex/dsh-taskbridge.toml`（移除顶层手管底层工作区与重复等待段落，篇幅缩减约 73%），保留完整 P0 规划、静默等待、单次审批、原生提问、派工回执核对（含 `agentTeamsOrigin` 与 `team.enabled`）、断线防重与检查点落盘纪律，并登记 `1.7.1` 原版哈希支持无感升级。
  - 去除顶层规则与设置页说明中对用户可配监控阈值（自检/运行进度检查分钟数）的硬编码，全部动态跟随 DSH 插件设置。
- **润色中英文插件介绍与文档**：重写 `docs/INTRODUCTION.zh.md`、`docs/INTRODUCTION.md`、`README.md` 开头及 `locale/*.json`，新增 `docs/antigravity-integration.md`（含 Antigravity 首次调用 `delegate_*` 放行提示），统一同步 `1.7.0+` 实际监控计时口径与 2.0 Claude Code 接入规划。
- **工程细节补齐**：补全 `ANTIGRAVITY_*` / `CODEX_*` 错误码映射与中文提示，对齐客户端导出面与 `lib/client.d.ts`。

## 安装与升级

- 可通过 DSH **插件 → 添加插件** 安装 `dsh-taskbridge`，或下载下方 `dsh-taskbridge-1.8.0.tgz` 本地安装。
- 从 `1.7.1` 升级时，DSH 启动后会自动刷新未修改过的 Codex 托管模板并保留自定义配置；如需接入 Antigravity，打开 **DSH TaskBridge 设置 → Antigravity 集成** 点击 **安装 / 更新 Antigravity 插件** 即可。
