# DSH TaskBridge 1.9.1 更新说明

## 摘要

`1.9.1` 为文案与体验优化补丁版，不改变 `1.9.0` 的 MCP 协议、隔离机制与执行核心，重点聚焦插件简介、文档术语和 DSH 前端提示的一致性：

1. **重写插件安装简介（去除具体跑分数字，聚焦设计与功能）**：更新 `package.json`、`locale/zh.json` 与 `locale/en.json`，去掉具体百分比数值，改为以「上层宿主端」为主语概括说明插件的功能定位与设计意图，并在末尾交代当前已支持的宿主端（Codex、Antigravity）与 `2.0` 路线（Claude Code）。
2. **中英文介绍全文术语统一**：将 `README.md`、`docs/INTRODUCTION.zh.md`、`docs/INTRODUCTION.md` 与 `docs/claude-code.md` 中混用的「指挥端 / 指挥官 / 跨客户端 / 客户端支持路线」等称谓统一收口为「宿主端 / 跨宿主 / host」。
3. **DSH 插件设置界面前端文案同步**：清理 `src/client/api.js` 与 `src/client/index.jsx` 中残留的「等待宿主（Codex）审查」「等待本机指挥官决定」等旧文案，统一改为「等待宿主端审查」「等待宿主端决定」并重建 `lib/client.js`。
4. **1.9.0 无感升级支持**：在 `src/codex/installer.js` 中登记已发布 `1.9.0` Codex 原生技能（LF / CRLF）的精确 SHA-256 哈希，升级到 `1.9.1` 时未修改过的托管文件可自动刷新，用户自定义修改原样保留。

## 升级说明

- **从 `1.9.0` 或更早版本升级**：在 DSH 插件管理页直接升级或安装 `dsh-taskbridge-1.9.1.tgz` 并启用即可；既有配置、本机调用开关状态与历史任务记录全部原样保留。
