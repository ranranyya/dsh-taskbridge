# 1.5.0 Codex等待阶段token与账单对照

核算日期：2026年11月15日。所有时段均为北京时间。

## 可以写入升级报告的结论

**这次真实记录中，等待相关token从9,986,839降至457,224，样本总量减少95.42%；按DSH任务实际执行时长折算，等待相关token/分钟减少94.46%。只比较同类“外层续等”动作，token/分钟减少90.07%。**

上述是不同任务的观察性样本对照，不是同一开发任务的受控A/B试验，不是整个Codex会话、全天账单或所有用户的固定节省率。

## 数据及匹配方法

- 使用用户提供的 `usage_2026-11-14_to_2026-11-15.csv`，共910条账单记录。
- 对照同一Codex聊天的模型响应级用量记录。两组宿主账单模型标识均为 `gpt-6.1-sol`。
- 按非缓存输入、缓存读取和输出三项用量精确匹配，每条只有一个候选。旧任务83条相关响应、本次邻近时段29条响应均找到唯一匹配；本节只抽取明确属于等待的动作。
- 本机 `input_tokens` 已含缓存输入；CSV的 `Input Tokens` 在这些匹配中是非缓存部分。因此使用 `input_tokens - cached_input_tokens` 对齐，不重复相加；输出已含对应思考输出时不再另加reasoning。
- 以工具调用及响应ID归类进入等待、外层续等、审批和审查。不能只按CSV时间裁切：账单时间与本机记录约有16秒差异，而且长工具后的token_count事件可能晚于响应级用量记录。
- 金额采用 `Billed Cost` 原始单位，CSV未标币种。没有再次乘2.5倍率，也没有把它解释成官方价格。
- 原始账单含API标签和IP信息，不随插件分发。公开文档只给汇总；本机保存脱敏匹配元数据与复算结果。

## 交付后审查成本不能省略

新验收从派工到收到交付，合计4条模型响应、609,162 token，Billed Cost为0.20742350。它包含派工与上述3条等待响应，**不包含交付后的独立核对、审查写回和报告**。

计入交付后的独立核对、审查写回和报告，本次完整验收共有9条模型响应、1,411,939 token，Billed Cost为0.68073650。其中交付后5条响应合计802,777 token、0.47331300。

这部分仍有必要成本，不能把等待阶段的95.42%降幅套到完整任务。旧任务在提供方冷却后失败，且有29次审批，因此没有相同边界、相同工作量的完整任务对照，不计算整轮节省率。

## 不能作出的宣传

- 不写“1.5.0所有任务节省95%token”“Codex完全不再消耗token”或“跨客户端零唤醒”。
- 旧任务有29次审批，新20分钟任务没有审批，不能把83次与4次的全部差额归因于静默等待实现。
- 两组缓存上下文大小不同；缓存token按不同价格计费，token降幅与费用降幅分别列出。
- 程序内部51次观察、50次心跳不是51次GPT响应。新样本仍存在2次真实外层续等模型响应。
- 只读 `delegate_metrics` 仍不直接观测宿主模型token；本文来自用户账单与本机模型记录的独立核算。
