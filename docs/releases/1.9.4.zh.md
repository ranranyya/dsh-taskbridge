# DSH TaskBridge 1.9.4 更新说明

## 摘要

`1.9.4` 是面向 **零协议破坏省 Token 瘦身与轻度清淤** 的补丁版本，不改动任何 MCP 工具名、参数名、类型、`enum`、`required`、`additionalProperties`、`annotations` 或后端 HTTP 路由，核心改进如下：

1. **MCP 会话初始化与工具目录上下文大幅压缩（直降 75%–87%）**：
   - 压缩 `src/mcp/server.js` 中的 `initialize.instructions` 握手说明（`7,475 → 436` 字符，直降 **94.2%**）与 11 个 `delegate_*` 工具的 Schema 描述文案（`JSON.stringify(TOOLS)` 由 `38,047 → 10,972` 字符，直降 **71.2%**），在 100% 保留参数结构契约与既有行为约束的同时，将宿主每次会话加载的 MCP 工具目录总字符数从 **`45,522` 字符降至 `11,408` 字符**（净降 **74.9%**；在按工具拼接全局说明的宿主场景下最坏膨胀由 **`120,272` 字符降至 `15,768` 字符**，直降 **86.9%**）。
   - 在 `tests/mcp.test.js` 新增防回退上限单测，锁死 `initialize.instructions <= 500` 字符与 `JSON.stringify(TOOLS) <= 11,500` 字符，防止后续迭代重新塞入长篇教程。
   - **Codex 真机省流复验**：会话冷启动首轮总输入压降至 `18,126` tokens（未缓存仅 `3,918`）；已完赛的 `T0A–T4` 六题 `6/6` 全满分（均分 `100`），其中小型题 `T1` 有效 Token 压至 **`45,033`**（较 `1.9.3` 降 **39.5%–49.1%**，历史上首次反超无插件基线 **`+14.66%`**），多模块题 `T3` 有效 Token 压至 **`60,047`**（较无插件基线净省 **`+27.55%`**，含缓存总 Token `785,551` 创代际最低）。
2. **清理客户端零调用死组件并重建产物**：
   - 删除 `src/client/index.jsx` 中全仓零引用的 4 个历史遗留组件（`ConnectivityLayer`、`LegacyAuthorizationPanel`、`ProviderEditor`、`LegacyProvidersPanel`）及对应 6 个仅由其使用的导入符号（净减 `660` 行源码），重新构建并校验 `lib/client.js`。
3. **清理未公开发布的测试版模板哈希并补登 `1.9.3` 正式版升级哈希**：
   - 在 `src/codex/installer.js` 的 `KNOWN_SKILL_TEMPLATES` 补登 `1.9.3` 正式版 Codex 技能 `SKILL.md` 的 LF / CRLF 双哈希，并移除所有未公开发布的 `1.9.0-test*`、`1.9.0-pre`、`1.9.0-preview*`、`1.9.2-test*`、`1.9.3-test*` 临时测试包哈希，仅保留正式公开发布版本（`1.9.0`–`1.9.3`）。
   - 在 `src/antigravity/installer.js` 的 `KNOWN_PRIOR_ANTIGRAVITY_FILES` 中移除内部未公开发布的 `1.9.0-test*` / `preview*` 哈希，仅保留正式发布版（`1.8.0`、`1.8.1`、`1.9.0`–`1.9.2`；当前模板未变）。
   - 同步收紧对应升级单测与防复发规范：本地测试包续装直接依赖 `~/.dsh/data/dsh-delegate/*-ownership` 本机所有权账本，严禁再向源码写入临时测试版哈希。
4. **仓库根目录瘦身、双语落地页升级与双端公开 CI**：
   - 将随包分发的 Codex 与 Antigravity 生成产物从根目录 `codex/`、`antigravity/` 统一收敛至 `integrations/targets/{codex,antigravity}/`（用户机器上的实际安装路径与文件内容字节保持 100% 不变），移除根目录遗留交接文档与未维护的 `pnpm-lock.yaml`，并将内部规范 `SPEC.md` 与市场位图图标 `icon-256.png` 收纳至 `docs/`。
   - 重构双语根入口（英文 `README.md` + 中文 `README.zh-CN.md`）首屏动线，补充「60 秒连通首检」验证指引与 `glama.json` 索引声明。
   - 修复干净检出环境下 `tests/continuation-auth.test.js` 的 `.cache` 目录自动创建并统一 `.gitattributes` 跨平台 LF 行尾归一化，新增 `.github/workflows/ci.yml` 在 Ubuntu 与 Windows 双平台持续执行构建同步、包体积与全量测试校验。

## 升级说明

- **从 `1.9.3`、`1.9.2`、`1.9.1`、`1.9.0` 或更早版本升级**：在 DSH 插件管理页直接升级或本地安装 `dsh-taskbridge-1.9.4.tgz` 并启用；DSH 启动自检会自动将未修改过的旧版 Codex / Antigravity 托管技能刷新至 `1.9.4`（也可在插件设置页对应集成标签手动点击更新），重开宿主会话即可立即享受更轻量的 MCP 工具目录上下文。既有接口配置、本机调用开关与历史任务记录全部原样保留。
