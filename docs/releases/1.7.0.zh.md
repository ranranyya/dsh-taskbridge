# TaskBridge 1.7.0

- 「任务记录」会自动显示新任务，保留工作标题。可按日期筛选，按执行链清理记录，也可打开任务原来的 DSH 会话。清理记录会保留源码和 DSH 会话。入口在**插件设置页的「任务记录」标签**；左侧侧栏不再有独立的「TaskBridge 任务」行。
- 左侧保留 DSH 原生工作区列表（原名、顺序、搜索、会话与菜单都不变）。「工作区 → 视图选项 → 按工作区树」显示可折叠的 TaskBridge 根工作区，展开后是隔离任务工作区和对话，旁边仍可访问原有工作区。工作区菜单可移除该工作区并保留文件及会话，对话菜单可归档和取消归档。共享任务沿用原项目中的原生工作区；经 TaskBridge 派出的会话在它自己的原生行里带一个很小的标记（「派工」／「派工 · 隔离」）。
- 同一项目可同时派发多个独立的隔离任务。每个工作包有自己的 DSH 会话和执行目录，各占一个并发名额。同一个共享目录一次只允许一个执行任务。
- 任务实际运行满 10 分钟时，插件在本机自检一次。Codex 连续 40 分钟未收到新成果时，插件会提醒 Codex 检查。两项可分别调整或关闭，提醒不会中止任务。
- 智能体协作默认关闭，可由用户设置，也可随单次派工选择。续接默认保留原会话的选择。任务的规划与交付验收由 Codex 负责。
- Codex 集成可识别和升级插件托管的旧智能体文件，保留用户的自定义设置。「安装 / 更新 TaskBridge 智能体」可重新配置集成，「仅修复 MCP 配置」只处理连接。

在 DSH 的「添加插件」中安装 `dsh-taskbridge-1.7.0.tgz`。已有 TaskBridge 的用户可用本地包升级。
