# DSH TaskBridge 1.5.2 更新说明

发布日期：2026 年 11 月 15 日。安装标识：`dsh-taskbridge@1.5.2`。

**这次专门更新插件介绍，帮助新用户更快了解 TaskBridge 能做什么、如何接入与开始派工。功能沿用 1.5.1。**

## 更新内容

- **列表简介**：讲清“让 Codex 指挥 DSH”的定位，突出在插件中选择已有 API、执行模型与思考强度，以及静默等待、审批、审查和原会话续接。
- **中英文详情**：按产品用途、完整任务流程、核心功能和上手步骤重新组织，补充设置表、任务状态、实际派工示例、常见问题和中英文任务流程图。
- **README**：先介绍产品和使用价值，再提供版本更新与技术文档，方便从 GitHub 或 npm 了解项目。
- **能力说明**：当前仅支持 Codex 端；Claude Code 与 Claude Desktop 接入预计在 2.0 上线。同步修订旧的 Claude 接入说明，避免将规划功能写成已上线能力。

## 功能与升级

API／模型选择、静默等待、权限审批、集中审查和同任务续接的行为保持 1.5.1。同步发布版本及未修改的 1.5.1 Codex 托管模板身份，支持正常升级；用户自定义配置仍保留。

已有功能的验收范围与已知限制见 [1.5.1 更新说明](1.5.1.zh.md)。本次不新增执行通道，不宣称新的 token 节省比例。

## 更新方式

在 DSH 插件管理中更新 `dsh-taskbridge`，或在“添加插件”中输入 `dsh-taskbridge@1.5.2`；也可安装 GitHub Release 提供的 `dsh-taskbridge-1.5.2.tgz`。区域镜像尚未同步时请选择 npm 官方源。

本项目自定义插件索引随正式 Release 更新。已安装插件的介绍随本次更新显示；发现页和镜像可能需要刷新缓存。
