# TaskBridge 1.8.1

## 核心更新

- **任务记录联动清理与历史孤儿扫除**：
  - 设置页「任务记录」新增**快捷勾选预设**（全部可清理 / 仅已通过验收 / 仅失败·已取消·已中断）与三项按需勾选的**联动清理**能力：归档关联 DSH 派工会话、移除隔离工作树目录与临时工作区、递归清理已变空的规划父节点。
  - **严格按隔离模式保护现场**：`worktree` 隔离任务可按需一并移除受管工作树与临时工作区；`shared` 共享任务绝不删除主项目源码目录与共享工作区，仅按勾选项归档对应派工会话。
  - **支持清理重启中断记录**：将 `interrupted`（DSH 重启导致且永不恢复的终态历史记录）纳入可手动清理范围并归入「失败·取消·中断」快捷预设，同时打通底层 `HistoryStore.deleteMany` 原子删除。
  - **一键扫除历史残留**：新增 `POST /api/dsh-delegate/tasks/cleanup-orphans` 与设置页入口，扫描并清理已删历史记录残留的孤儿隔离工作树目录、临时工作区与失效会话映射。
- **三重指挥端省 Token 优化**：
  - **Antigravity 轻量后台子智能体隔离**：默认通过 `dsh-taskbridge` 子智能体（`Model: "flash"`）在后台承载预检、静默等待与常规权限审批，并仅回传结构化精简摘要，避免多轮中间载荷灌入主旗舰模型上下文；修正 YAML `tools:` 不应声明 `call_mcp_tool`（由 `mcp_config.json` 自动注入）的真机启动问题并加防回归断言。
  - **Worker 原生文件工具优先**：底层 `worker-prompt.js` 明确要求读写、检索文件与日志优先使用原生工具而非 Shell（`pwsh`/`powershell`/`cmd`/`bash`），禁止未要求的外部网络请求，显著降低 Windows 沙箱内的无效审批回合。
  - **MCP 载荷大幅瘦身**：全量 MCP 工具响应改为单行紧凑 JSON 序列化；`delegate_wait` / `delegate_permission_decide` / `delegate_question_answer` 在交互暂停回合剔除重复的 `task.activity`、`selfCheck`、`route`、`reviewPersistence` 监控大块（`attention` 与终态仍完整保留）。
- **共享模式工作区命名保护**：
  - 仅在 `worktree` 隔离模式首次新建专属任务工作区时以 `delegate_submit.title` 命名；`shared` 共享模式首次为项目创建原生工作区时保留项目原有名称，不再被第一笔单次任务标题覆盖。
- **规则、MCP 握手契约、文档与全新架构图全面刷新**：
  - 修正 MCP `initialize` 握手下发 `instructions`、`delegate_wait` 工具描述与兜底提示中的旧版 10 分钟静默口径，对齐 `1.7.0+` 实际进度检查与默认无总执行超时契约。
  - 在双端规则、设置页与中英文介绍中写透“隔离与共享模式均要求已提交的 Git 仓库根目录”及非代码问答触发边界；补齐双端 `delegate_question_answer` 防重发、`confirmation: "unknown"` 复核、`interrupted` 三态区分与 `completionSummary` 分页对称性，并登记 `1.8.0` 精确升级哈希（Codex + Antigravity 均支持无感升级）。
  - 替换 `v1.5.2` 旧配图为全新中英文高清多端黑盒架构图（`docs/assets/taskbridge-workflow.{zh,en}.png`），修复 `README.md` 全部 10 处断链并刷新折叠区技术参考。

## 安装与升级

- 可通过 DSH **插件 → 添加插件** 安装或升级 `dsh-taskbridge`，或下载下方 `dsh-taskbridge-1.8.1.tgz` 本地安装。
- 从 `1.8.0` 升级时，DSH 启动后会自动刷新未修改过的 Codex 与 Antigravity 托管规则文件并保留自定义编辑；升级完成后建议重连 MCP 或重启一次 Antigravity / Codex 会话以加载新版紧凑 JSON MCP 进程与最新子智能体配置。
