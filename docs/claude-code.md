# Claude Code / Claude Desktop 接入计划

**当前版本已支持 Codex 与 Antigravity 宿主端一键接入；Claude Code 与 Claude Desktop 接入计划于 2.0 版本上线。**

TaskBridge 目前在插件设置页中提供 **Codex 集成** 与 **Antigravity 集成** 的一键安装、更新、仅修复 MCP 与卸载入口。Claude Code 与 Claude Desktop 尚未作为当前版本的正式宿主端提供；请先在已支持的宿主端中使用现有的派工、等待、审批和审查流程。

## 宿主端支持路线

| 宿主端 | 当前状态 | 预计版本 |
| --- | --- | --- |
| Codex | 已支持 | 当前版本可用 |
| Antigravity | 已支持 | 当前版本可用 |
| Claude Code | 接入尚未上线 | 2.0 |
| Claude Desktop | 接入尚未上线 | 2.0 |

2.0 的目标是让 Claude Code 和 Claude Desktop 也复用同一套标准 MCP 服务接口，作为上层宿主端调用 DSH 插件中配置的执行 API、模型与思考强度。

当前安装步骤请查看 [TaskBridge 中文介绍](INTRODUCTION.zh.md)、[Codex 集成说明](codex-integration.md) 与 [Antigravity 集成说明](antigravity-integration.md)。
